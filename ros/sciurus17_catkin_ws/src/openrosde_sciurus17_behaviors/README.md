# openrosde_sciurus17_behaviors

The `openrosde_sciurus17_behaviors` directory contains the FlexBE behavior packages for the RT Sciurus17 platform.

- Maintainer: Lotfi El Hafi ([lotfi@coarobo.com](mailto:lotfi@coarobo.com)).
- Author: Lotfi El Hafi ([lotfi@coarobo.com](mailto:lotfi@coarobo.com)).

## Usage

Start the FlexBE behavior engine and app:

```shell
roslaunch openrosde_launch flexbe_app_default.launch
```

## Behaviors

| Behavior | Description |
| --- | --- |
| `Sciurus17 Example Behavior` | Example looping dual-arm dance between the `r_arm_init_pose` and `l_arm_init_pose` named configurations |
