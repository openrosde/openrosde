# openrosde_cobotta_behaviors

The `openrosde_cobotta_behaviors` directory contains the FlexBE behavior packages for the Denso COBOTTA platform.

- Maintainer: Lotfi El Hafi ([lotfi@coarobo.com](mailto:lotfi@coarobo.com)).
- Author: Lotfi El Hafi ([lotfi@coarobo.com](mailto:lotfi@coarobo.com)).

## Usage

Start the FlexBE behavior engine and app:

```shell
roslaunch openrosde_launch flexbe_app_default.launch
```

## Behaviors

| Behavior | Description |
| --- | --- |
| `COBOTTA Example Behavior` | Example looping arm dance between the `home` and `up` named configurations |
